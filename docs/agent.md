# 1. 문서 개요

- 이 문서서는 AI Agent 가 프로그램 작성시 먼저 참고 해야함.

# 2. 요구사항

- docs/sample_dht.py 파일은 라즈베리파이에서 dht2 온습도계 센서를 2초마다 수집하는 참조용 샘플코드임.
- DHT22 센서의 온도 습도 정보를 받아 서버로 전송하는 프로그램 개발 
- gitignore 에 등록할 파일
  - env/.env

## 2.1. 상세 요구사항 

- config/.env 파일에 서버 접속정보를 기록함. 이 파일은 gitignore 에 기록하여 git 으로 관리되지 않도록 함.
- config/config.yml 파일에는 프로그램에서 관리할 설정값들을 관리함
  - type 은 기본으로 TEMP_HUMIDITY 
  - type 은 현재 가능한 값은 다음과 같음. TEMP_HUMIDITY, MIC
- 1분마다 섭씨 온도와 습도를 확인해야함
- 소프트웨어 타이머로 특정시간 (1분) 마다 측정하게 하고 이 값은 config.yml 에서 설정가능하게끔 함 

## 2.2. 프로그램 실행 명령어 입력시 요구사항 

- 프로그램 실행시 test/dummy/run 모드인지 파라미터로 받아서 실행
- test 모드일때는 센서값을 1분마다 측정하되. 서버로 보내지 않고 로그로만 출력 (즉 센서가 정상적으로 동작하는지 확인하는 용도)
- dummy 모드일 경우 센서값을 가져오지 않고 임의로 다음 두가지 값을 1분마다 반복해서 보냄. 보낼때 로그에는 dummy value 라고 표시 (즉 서버와의 통신만 확인하는 용도)
  - 섭씨 23.5도, 습도 50% / 섭씨 24.0도, 습도 55%
- run 모드일경우 실제 센서로 측정된값을 보냄
  - 현재 GPIO 의 어떤 위치에 연결할지모르니 정확한 값이 필요할경우 config.yml 에 설정값으로 일단 설정하도록 함 
- run 모드로 실행했을때 .env 파일을 확인하여 `api_key`, `device_key` 값을 확인함.
  - 하나라도 없으면 "디바이스가 등록되지 않았습니다." 메시지 출력 후 종료 
- claim code 값을 프로그램 첫 실행시 입력받음. (파라미터로 입력받음. 해당 파라미터 값이 있으면 프로그램을처음 실행하는것으로 간주)
  - claim code 값을 입력받아서 프로그램이 실행될 경우 서버의 `POST /devices/caim` 호출하여 디바이스 등록
    - request body
      - `claim_code` : 프로그램 실행시 파라미터로 입력받은 claim code. 입력받은 그대로 전달함
      - `name` : config 에서 획득한 type 을 그대로 사용
      - `type` : config 에서 획득한 type 을 그대로 사용
      - `location_name` : "우리집" 이란 문자열 전송 
    - 200 or 201 응답을 받을경우 정상등록.
      - 정상응답일경우 Response Body 의 `api_key` 와, `device.device_key` 를 .env 에 저장 (기존에 값이 있으면 overwrite)
      - 위 내용을 저장후 온도 습도 전송 api 호출 시 사용 
      - 정상응답이 아닐경우 "디바이스 등록 실패" 라는 메시지 출력후 프로그램 중료 
  - 온습도 저장 API
    - Method/URI : `POST /climate/{deviceKey}`
    - Request Header : `Authorization` 헤더 . `api_key` 를 여기에 사용
    - Body :
      - `temperature_c` : 필수값. 측정된 섭씨온도
      - `humidity` : 옵션값. 측정된 습도

## 2.3. .env 파일 활용

- 해당 파일은 git 으로 관리하지 않고. .env.example 파일을 만들어서 샘플 예시로만 관리함 
- 서버 접속정보를 설정으로 기록함. 
- 디바이스 아이디 정보를 기록함.
  - 디바이스 아이디 정보가 없다면 프로그램을 실행할수없음
  - `api_key` 와 `device_key` 를 저장함 

## 2.4. 로그파일 활용

- 로그는 edge.yyyymmdd.hh.log 형태의 파일로 기록
- 로그파일 내에는 일시, 로그레벨, 로그내용 기록
- 컨테이너 내의 로그파일은 호스트의 log 폴더내에 마운트하여 기록하도록함
- 로그는 7일간만 유지 그 보다 지난 로그는 삭제하도록 함
